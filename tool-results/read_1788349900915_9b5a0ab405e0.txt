   102→
   103→#### Architecture Decisions:
   104→- **Auth**: All mutation endpoints (POST/PUT/DELETE) check `x-user-id` header; GET endpoints are public (read-only)
   105→- **Pagination**: Standard `page`+`pageSize` query params with `{ data, total, page, pageSize }` response
   106→- **Transactions**: Sales creation, returns, restocks, inventory adjustments all use `db.$transaction()`
   107→- **Transaction numbers**: `TXN-YYYYMMDD-XXXX` (sequential per day), `RET-YYYYMMDD-XXXX`, `RCP-YYYYMMDD-XXXX`
   108→- **Soft deletes**: Products, categories, suppliers, customers, staff use `isActive=false`; expenses use hard delete
   109→- **No `next-auth` in API routes**: Custom header-based auth (`x-user-id`)
   110→- **Staff passwords**: Never included in responses; hashed with bcryptjs (salt 10) on create/update
